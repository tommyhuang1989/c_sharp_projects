# 异步编程

## 1.Task类

    Task 类是对异步编程和多线程等操作的封装
    通过语法糖 async/await 来启用异步
    通过 Task.Run() 开启多线程

## 2.异步编程和同步编程

    同步编程，从上到下按行执行，遇到耗时操作会阻塞

    异步编程，通过语法糖 async/await，能实现不阻塞

## 3.异步编程和多线程

    异步是编程概念，核心是不阻塞，异步编程不一定启动多线程，要看异步源：如果只是 async/await 调用，就只是 I/O；如果是 Task.Run(), 就涉及多线程了（线程池）
    
    而多线程是一种技术

## 4.I/O密集和CPU密集

    I/O 密集：涉及 I/O（数据库、Redis等）、涉及网络（Http、各种网络 API），此时使用 async/await

    CPU密集：加密算法、复杂的计算等，此时使用 Task.Run()

## 5.异步的不阻塞

    当使用 await 时，当前线程状态被暂停，但并不阻塞，但是 await 后面的代码需要等待异步操作完成才会执行；

    而外层的线程可以继续执行其他操作；但如果外层的线程也是直接 await 异步方法，后续的代码也会进行等待；

    所以只要遇到 await 方法就会暂停，线程被释放，回归到线程池，被分配去干其他的任务，当异步任务完成时，线程池就会再分配一个线程来接着执行 await 后面的代码（这个线程可能不是原来那一个）

    eg:

    public async Task main() {
        Console.WriteLine("start main method.");

        await TestAsync();//从 TestAsync() 返回的线程，继续被释放，回到线程池去干其他任务，等待 TestAsync() 执行完毕，线程池会再分配一个线程回来接着执行剩下的代码

        Console.WriteLine("End main method");//需要等待 TestAsync() 执行完毕才会执行；
    }

    public async Task TestAsync() {
        Console.WriteLine("Start Test method");

        await Task.Delay(2000);//此时当前方法暂停，线程回到 main() 中；

        Console.WriteLine("End Test method");//需要等2000ms才会执行；
    }

### 7.ConfigureAwait() 控制是否需要切回上下文

    默认为 true，会切换多线程（后续需要调用UI线程时，必须切回）

    false，表示不切换回线程上下文（与UI线程无关时，设置为false减少切回，反而能节约资源）
